What is different in this new Part 3 website
In Part 3, the website was completely upgraded into an interactive and dynamic website. All of the inline styles from Part 2 were removed and replaced with one shared external stylesheet, css/style.css, which makes the site load faster, look consistent on every page and work properly on mobile phones. Javascript was added to make the site dynamic. The programmes and news stories are no longer hardcoded, they now load from Javascript arrays, and on the Programmes page the user can search,filter and sort. The same search also filters the news news stories. New interactive features were also added including FAQ accordion on the Home and About pages, a Donate modal that opens on every page, a photo gallery with a lightbox, fade-in animations on scroll and a real interactive Leaflet map on the Contact page, which the user can drag and zoom.Plus two working forms: enquiry.html which relies on the page with cost and availability, and contact.html which send a compiled email to info@hopehaven.org.za. Part 3 also adds full on-page SEO, robots.txt, sitemap.xml, page speed optimisation and security measures,all using one shared CSS file and regular GITHUb commits
